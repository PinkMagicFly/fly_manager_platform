## 一、项目概述

### 1.1 业务背景与系统定位
低空经济成为国家战略性新兴产业，低空物流面临空域供需矛盾、审批周期长、在途监管手段匮乏、多主体信息割裂等痛点。本项目建设“**翔云·低空智慧物流运营平台**”，构建城市级/区域级低空物流运营一体化数字底座，实现低空飞行**「申请 — 审批 — 调度 — 监控 — 结算」全生命周期管理**（需求依据：《天枢·低空智能运营管控平台 项目开发计划书》PDF，本项目以其为需求书实施）。

### 1.2 核心业务闭环（十步主链路，唯一权威）
```
①注册实名 → ②客户下单[地址校验+禁运品+路线预检+费用试算] → 订单·待支付
③在线支付 → 待接单 → ④商户接单/拒单(原因) → 待调度
⑤商户调度台生成调度方案[推荐机型/机长+绘航线+围栏校验] → 提交飞行任务 → 任务·待审批
⑥空管审批：通过→空域时段确权+锁定无人机/机长/场站+订单→待执飞
           驳回(原因必填)→订单停留待调度，重新规划再报（资源零占用）
⑦机长确认起飞[守卫:任务已批准] → 订单·飞行中，任务·执行中，无人机·任务中
⑧在途监控：机长定时上报轨迹；空域态势图实时图层；订单详情轨迹回放与申报航线比对
   异常支线：机长故障上报 → 订单·异常中断 + 自动生成严重告警 → 告警环处置
⑨送达签收 → 订单·已送达，任务·已完成，无人机·闲置，自动出账结算单
⑩对账开票：商户核对→已对账→发票申请 → 闭环
```
**时序铁律（PDF §9.2）**：先申报审批、后锁定资源——调度方案随任务单一并提交，**审批通过后才分配/锁定设备与空域**。

## 二、业务规则基线（唯一权威，一切代码与文档冲突以本章为准）

### 2.1 双单据模型
- **订单 `cargo_order`**：客户端视角粗粒度；**飞行任务 `flight_apply`**：运营端视角（含调度方案+审批流）；
- 关系 **1:1**（`order_id>0` 唯一约束，一单一任务）；任务可独立存在（`order_id=0` 自主飞行，如巡检）。

### 2.2 订单状态机（八态）

| 码 | 状态 | 进入动作 | 前置守卫 | 出口 |
|----|------|----------|----------|------|
| 10 | 待支付 | 客户提交（移动端） | 地址在服务空域、非禁运品、路线预检、费用试算（读参数） | 支付→20；超时/取消→70 |
| 20 | 待接单 | 支付成功 | —— | 接单→30；拒单(原因)/超时→70 |
| 30 | 待调度 | 商户接单 | —— | 任务审批通过并锁定资源→40 |
| 40 | 待执飞 | **任务审批通过、分配设备与空域后系统置位** | 关联任务=已批准 | 起飞→50 |
| 50 | 飞行中 | 机长确认起飞 | 任务=已批准 | 送达→60；故障→80 |
| 60 | 已送达 | 机长确认送达 | —— | 自动出账 |
| 70 | 已取消 | 客户/商户/管理员/超时 | 仅 10/20/30 可取消；任务已批准需先撤任务并释放资源 | 终态 |
| 80 | 异常中断 | 机长故障上报（联动严重告警）/管理员接管 | 记录原因，走告警环 | 终态 |

### 2.3 飞行任务状态机（六态，无草稿）
`0待审批 →(空管通过) 1已批准[锁定资源+订单→40] / 2已驳回[原因必填，订单停留30] / 3已取消[商户撤回(仅0可撤)/管理员终止，已批准需释放资源] →(起飞) 4执行中 →(送达) 5已完成`
申报向导内编辑为临时态不落库，**直接提交即 0待审批**。

### 2.4 其余状态机
- **无人机五态**：`0闲置→1任务中→2维保中→3故障→4离线`；资源锁定与状态解耦（审批通过=绑定+场站预约+时段冲突校验；起飞才置任务中，送达/中断回闲置）；
- **商户入驻**：`待审核→已通过(主账号激活)/已驳回(原因必填)`；资质到期提前 7 天提醒；
- **告警**：`未处置→处置中→已关闭`（级别：一般/严重/紧急）；来源=机长故障上报自动生成 + 后台手工登记，**无自动侦测**；
- **工单**：`待处理→处理中→已关闭`（类型：咨询/投诉/异常）；
- **结算**：费用=基础费+空域费+加急费−优惠（**参数可配**）；送达自动出账 `待对账→已对账→已开票`。

### 2.5 单据联动与事务一致性（同一事务，任一步失败整体回滚）

| 触发 | 联动写库 |
|-------|----------|
| 提交飞行任务 | 任务 0待审批；**不锁任何资源、不动订单状态** |
| 审批通过 | 任务 1已批准 + 空域时段确权 + 锁定无人机（时段冲突校验）/机长/场站预约 + 订单→40 + 状态流水 |
| 审批驳回/撤销 | 任务 2/3；订单停留 30（资源零占用，无需回退） |
| 确认起飞 | 校验任务=已批准；任务 4执行中 + 订单→50 + 无人机→任务中 |
| 确认送达 | 任务 5已完成 + 订单→60 + 无人机→闲置 + 自动生成结算单 |
| 机长故障上报 | 订单→80 + 自动生成严重级告警 |
| 敏感操作 | `audit_log` 审计（真实 IP 穿透 Nginx） |
